**Stage 4 (#10, the site) is built on `europe`, 2026-08-22 and 2026-08-23**: a region-agnostic front end under `site/` and the development harness under `dev/` that makes it testable before R2 exists. Nothing in the code names a region; the run of record only appears in defaults and in the CI budget list. What the site does: the path is `/<region>/<unit>` and the rest of the state rides in the hash (scenario, pole, position, basemap, language), the explore layer decodes the published PMTiles class archives with 255 as nodata (#26) and `min_zoom` from their metadata, a tap anywhere reads the class out, zoom 12 and above swaps in the 50 m detail raster of the open pole, the card carries the headline sentence, the regional rank and the ten poles with their nearest road and settlement (a null settlement name and a blank detail raster both render), the ranking panel lists every unit of the region sorted by the active scenario and becomes a three-height bottom sheet on phones, "Locate me" opens the visitor's unit, and the About dialog explains the method in both languages. `worker.js` stamps the visitor's coarse country and region from `request.cf` into the page as a meta tag, so the first screen needs no geolocation prompt, and logs one Analytics Engine row of eight blobs (the LT site's six plus the landing region and unit) to `poles_views`, or `poles_preview_views` on the preview. ## What works

A bullet here works today, end to end. Anything that waits on a step, a credential or a rerun is either marked **Not yet** on its own bullet or lives in the list below; nothing sits between the two lists.

- The pipeline through publishing for two regions (`pipeline/`, branch `europe`; `poles run north-america` ran the same stages on the 2026-08-22 snapshot on 2026-08-23, 64 units, numbers in spec 3.3): `poles run europe` fetches and verifies the six Geofabrik PBFs, extracts highways, boundaries, places, water and land into FlatGeobuf layers, classifies roads into scenarios A and B, computes the 250 m distance grids (`work/europe/2026-08-19/grid/dist_A.tif`, `dist_B.tif`, `land.tif`, 28,588 x 23,625 cells, EPSG:3035) with a tiled exact transform, assembles 52 country units from the OSM boundary relations, searches each unit and scenario by branch-and-bound down to an exact 5 m sweep in the local UTM zone with nearest road and nearest settlement attribution, validates every published pole against an independent geodesic path (report, contact sheet, non-zero exit on a blocking failure), and publishes: it drops the poles validation excluded, quantises the grids into class rasters with the edge band and the sea masked, builds a z0 to z9 PMTiles archive per scenario, renders a 50 m detail raster per published pole with a georeference sidecar, uploads the archives, the detail rasters and the validation artefacts to R2 and verifies each key with a HEAD and a range request, then writes the four site JSON documents against the frozen schemas in `poles/schemas/`; every stage resumes from `done.json` and the long sub-steps from per-artefact `.ok` markers; the same code runs in the container (`pipeline/Dockerfile`) and CI (`pipeline-tests.yml`). The upload and the verification ran for real on 2026-08-23 for both regions (bucket `poles-data`, 4,352 objects, 704.8 MB)
- Europe site (`site/` plus `dev/`, branch `europe`, live on the preview worker since 2026-08-23): plain ES modules, no build step, vendored Leaflet 1.9.4 and pmtiles 4.5.0; `/<region>/<unit>` paths with the rest of the state in the hash, the explore layer from the PMTiles class archives, a 50 m detail overlay from zoom 12, the readout, the card, the ranking panel and phone sheet, "Locate me" from the worker's visitor meta tag, the About dialog, lt and en. Behind it: the dev server and dev site JSON in `dev/`, 59 node unit tests, the eleven screenshots in `docs/screenshots/`, and CI that deploys the preview worker from `europe`, verifies the commit through `version.json` and measures the first screen against a 256 KB budget. Since 2026-08-23 it serves both regions, the JSON from `site/data/` and the archives and detail rasters from R2
- LT map with scenarios A and B, computed on a 50 m grid from a 2026-08-17 OSM snapshot; spots and distance bands published in `site/data/` (~5 MB)
- Compute pipeline `scripts/01..06` (download -> prepare -> compute -> report -> webdata -> sitedata); heavy inputs gitignored and regenerable
- Site: lt/en i18n, URL-hash state, satellite default basemap, mobile bottom pill, dark variant
- Analytics: edge logger to Workers Analytics Engine (ground truth since 2026-08-18), plus raw asset request counts for volume. The CF Web Analytics beacon was removed 2026-08-20 as redundant once the mirror was gone.
- Deploys: Cloudflare Worker via CI on push (since 2026-08-20, `deploy-cloudflare.yml`) with a post-deploy verify job. Cloudflare is the only target; the GitHub Pages mirror was removed 2026-08-20.
- Monitoring: UptimeRobot checks the live URL every 5 minutes with email alerts (since 2026-08-20)
- Launched 2026-08-17 via LinkedIn post
