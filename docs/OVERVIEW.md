**Stage 4 (#10, the site) is built on `europe`, 2026-08-22 and 2026-08-23**: a region-agnostic front end under `site/` and the development harness under `dev/` that makes it testable before R2 exists. Nothing in the code names a region; the run of record only appears in defaults and in the CI budget list. What the site does: the path is `/<region>/<unit>` and the rest of the state rides in the hash (scenario, pole, position, basemap, language), the explore layer decodes the published PMTiles class archives with 255 as nodata (#26) and `min_zoom` from their metadata, a tap anywhere reads the class out, zoom 12 and above swaps in the 50 m detail raster of the open pole, the card carries the headline sentence, the regional rank and the ten poles with their nearest road and settlement (a null settlement name and a blank detail raster both render), the ranking panel lists every unit of the region sorted by the active scenario and becomes a three-height bottom sheet on phones, "Locate me" opens the visitor's unit, and the About dialog explains the method in both languages. `worker.js` stamps the visitor's coarse country and region from `request.cf` into the page as a meta tag, so the first screen needs no geolocation prompt, and logs one Analytics Engine row of eight blobs (the LT site's six plus the landing region and unit) to `poles_views`, or `poles_preview_views` on the preview. The harness: `dev/serve.mjs` serves `site/` with the SPA rule, the dev JSON under `/data/` and the local publish directory under `/r2/` with HTTP ranges; `dev/site-json.py` builds the site documents from the run of record with a local `r2_base`; `node --test 'dev/tests/*.test.mjs'` is 52 unit tests over the router, data, i18n, palette, readout, card, ranking, detail, the dev server and the worker helpers, run in CI by `site-tests.yml`. `dev/screenshots.mjs` is the UI test suite: ten Playwright views written to `docs/screenshots/` with the basemap stubbed grey, the six desktop images byte-identical run to run. CI (`deploy-cloudflare.yml`) deploys the preview worker on every push to `europe`, writes `site/version.json` at deploy and verifies that exact commit is live, then measures the first screen against a 256 KB budget. Everything above was verified locally against the run of record through the dev server; the preview worker at `https://atokiausia-lietuva-preview.donatas-kasparavicius.workers.dev` has been live since the branch's first push on 2026-08-23 (commit 10abf6f, the final review's fix rounds included). **What waits on the R2 rerun**: `site/data/` carries no region JSON yet, so the deployed preview serves the SPA fallback for the data files and shows an empty map, the budget step runs with `JSON_STRICT: 0` and flips to 1 in the same commit that adds `site/data/<region>/`, and the first screen is only measured against real JSON after that. **Open, filed during the stage**: #30 (a pole on an islet narrower than a pixel gets an all-nodata detail raster, and the site shows the explore layer under it), #31 (the region name in the card's rank line is untranslated, fixed by adding a translated name at the R2 rerun), #32 (the phone vertical budget: the card is tall on small phones and the attribution height is a fragile constant), #33 ("Locate me" resolves the unit by bounding box; the proper fix is lazy unit outlines). #34 and #35 (the phone zoom control over the headline, the phone sheet opening at rank 1) were found by the screenshot suite and fixed before the push.

## What works

A bullet here works today, end to end. Anything that waits on a step, a credential or a rerun is either marked **Not yet** on its own bullet or lives in the list below; nothing sits between the two lists.

- Europe pipeline through publishing (`pipeline/`, branch `europe`): `poles run europe` fetches and verifies the six Geofabrik PBFs, extracts highways, boundaries, places, water and land into FlatGeobuf layers, classifies roads into scenarios A and B, computes the 250 m distance grids (`work/europe/2026-08-19/grid/dist_A.tif`, `dist_B.tif`, `land.tif`, 28,588 x 23,625 cells, EPSG:3035) with a tiled exact transform, assembles 52 country units from the OSM boundary relations, searches each unit and scenario by branch-and-bound down to an exact 5 m sweep in the local UTM zone with nearest road and nearest settlement attribution, validates every published pole against an independent geodesic path (report, contact sheet, non-zero exit on a blocking failure), and publishes: it drops the poles validation excluded, quantises the grids into class rasters with the edge band and the sea masked, builds a z0 to z9 PMTiles archive per scenario, renders a 50 m detail raster per published pole with a georeference sidecar, uploads the archives, the detail rasters and the validation artefacts to R2 and verifies each key with a HEAD and a range request, then writes the four site JSON documents against the frozen schemas in `poles/schemas/`; every stage resumes from `done.json` and the long sub-steps from per-artefact `.ok` markers; the same code runs in the container (`pipeline/Dockerfile`) and CI (`pipeline-tests.yml`). **Not yet on real data**: the upload and the site documents, which have run in tests only, because R2 is not enabled on the account (#9)
- Europe site (`site/` plus `dev/`, branch `europe`, live on the preview worker since 2026-08-23): plain ES modules, no build step, vendored Leaflet 1.9.4 and pmtiles 4.5.0; `/<region>/<unit>` paths with the rest of the state in the hash, the explore layer from the PMTiles class archives, a 50 m detail overlay from zoom 12, the readout, the card, the ranking panel and phone sheet, "Locate me" from the worker's visitor meta tag, the About dialog, lt and en. Behind it: the dev server and dev site JSON in `dev/`, 52 node unit tests, the ten screenshots in `docs/screenshots/`, and CI that deploys the preview worker from `europe`, verifies the commit through `version.json` and measures the first screen against a 256 KB budget. **Not yet**: it has no data to show until the R2 rerun writes `site/data/` (#9)
- LT map with scenarios A and B, computed on a 50 m grid from a 2026-08-17 OSM snapshot; spots and distance bands published in `site/data/` (~5 MB)
- Compute pipeline `scripts/01..06` (download -> prepare -> compute -> report -> webdata -> sitedata); heavy inputs gitignored and regenerable
- Site: lt/en i18n, URL-hash state, satellite default basemap, mobile bottom pill, dark variant
- Analytics: edge logger to Workers Analytics Engine (ground truth since 2026-08-18), plus raw asset request counts for volume. The CF Web Analytics beacon was removed 2026-08-20 as redundant once the mirror was gone.
- Deploys: Cloudflare Worker via CI on push (since 2026-08-20, `deploy-cloudflare.yml`) with a post-deploy verify job. Cloudflare is the only target; the GitHub Pages mirror was removed 2026-08-20.
- Monitoring: UptimeRobot checks the live URL every 5 minutes with email alerts (since 2026-08-20)
- Launched 2026-08-17 via LinkedIn post
